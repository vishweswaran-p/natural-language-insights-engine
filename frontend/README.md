# Frontend — Natural Language Insights Engine

Plain React + TypeScript + Vite SPA (no extra runtime dependencies).

```bash
cd frontend
cp .env.example .env   # VITE_API_BASE_URL points at the backend API
npm install
npm run dev            # http://localhost:5173
```

Requires the backend running (default `VITE_API_BASE_URL=http://localhost:1337/api`).
